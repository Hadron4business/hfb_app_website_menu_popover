Website Menu Popover

Ask visitors to confirm before they follow a website menu link.

The problem

Some menu links should not be followed blindly: a link to another shop, to a site for a different country, or to a page with different terms. A plain link takes the visitor away before they understand where they are going.

What you get

Per menu item

Switch the popover on for the menu items that need it. All other links behave as usual.

Your own text

Write the message the visitor sees, and translate it into every website language.

Continue or cancel

The visitor follows the link only after pressing Continue. Cancel, Escape or a click outside closes the dialog.

No code

Two fields in the standard menu editor. Nothing else to configure.

Any link

Works for internal pages and for external addresses.

Lightweight

A small script and no extra libraries.

How to use it

1
Open Website > Site > Menu Editor (in edit mode: Site > Menu Editor).
2
Open the menu item you want to confirm (search by name; the list is grouped by website).
3
Tick Show Popover. A Popover Text field appears.
4
Type the message, for example: "You are about to leave this shop. Continue?" and save.
5
Open the website and click the menu item: the dialog appears. The link is followed only after Continue.
6
To translate the text, use the translate icon next to Popover Text (language button on the field).

Good to know

  • The popover appears on the exact link set in the menu item's URL. Other links to the same address on the page (for example a button) also show it.
  • A menu item with sub-items (a dropdown) works too: set the popover on the sub-item you want to confirm.
  • Button labels (Continue / Cancel) follow the visitor's language and can be translated in Settings > Translations.
  • If a visitor has JavaScript disabled, the link simply works as a normal link.
